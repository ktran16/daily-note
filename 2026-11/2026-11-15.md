# Daily Notes - 2026-11-15

## 00:03 - [Data Engineering] dbt `--defer`: Building One Model Against Production Upstreams

You change one mart model. Your dev schema is empty, so `ref('stg_orders')` resolves to `dev_you.stg_orders` — which doesn't exist. The usual reflex is `dbt build --select +fct_orders`, rebuilding forty upstream models to test a one-line edit.

`--defer` fixes this. Given a production `manifest.json`, any node **not selected in this run** has its `ref()` rewritten to point at the production relation instead of your dev schema:

```bash
# Fetch the manifest produced by the last production run
mkdir -p prod-artifacts
aws s3 cp s3://dbt-artifacts/prod/manifest.json prod-artifacts/

dbt run --select fct_orders --defer --state prod-artifacts
# compiles to: from analytics.stg_orders  (not dev_you.stg_orders)
```

### The gotcha: defer prefers your environment

Default defer is not "always use prod." The rule is: use the deferred relation *only if the node does not already exist in your target schema*. So if you built `stg_orders` in dev three weeks ago, defer silently uses that stale copy, and you debug a discrepancy that doesn't exist in prod.

`--favor-state` inverts it — always take the state manifest's relation, even when a local copy exists:

```bash
dbt run --select fct_orders --defer --favor-state --state prod-artifacts
```

Use `--favor-state` in CI, where leftover relations from earlier runs are common. Leave it off locally when you *intend* to chain onto models you just built.

### Two more things that bite

- **Sources are never deferred.** `source()` always resolves to its configured database/schema. Defer rewrites `ref()` only.
- **`--state` does double duty.** It feeds both `state:modified` selection and defer. When the comparison manifest and the defer target should differ, split them with `--defer-state`.

Slim CI is just these two features composed:

```bash
dbt build --select state:modified+ --defer --favor-state --state prod-artifacts
```

Export `DBT_STATE=prod-artifacts` to stop retyping the path.
